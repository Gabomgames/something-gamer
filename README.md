# Something Gamer

### Yes, something for you ;)

Something Gamer é uma plataforma gamer desenvolvida pela Now Desenvolvimento Tech.

A proposta é reunir jogadores, seus jogos, conquistas, estatísticas e integrações com diferentes plataformas em um único ecossistema.

## Status

Em desenvolvimento.

## Principais recursos

- Perfis gamer
- Biblioteca de jogos
- Conquistas
- Estatísticas
- Sistema de reputação
- Integração com plataformas
- Plataforma web
- Aplicativo
